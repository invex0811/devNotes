## Готово

- **Этап 0.** Монорепозиторий на npm workspaces (`apps/web`, `packages/core`,
  `packages/mcp`), ESLint, Prettier, Vitest, CI с публикацией на GitHub Pages
  (https://invex0811.github.io/devNotes/), тёмная оболочка.
- **Этап 1.** Типы и схемы в `core`, хранилище в памяти, сетка, быстрый ввод с умными
  метками, диалог заметки, статусы, метки, цвет, закрепление, архив, поиск, проекты,
  фильтры. Всё работает по адресу `?demo=1`.
- **Этап 2.** Вход через Google (токен-модель GIS, только `drive.file`, токен только в
  памяти), поиск личной таблицы через Drive `appProperties` или её создание, хранилище
  на Sheets API за интерфейсом `DataStore`, кэш и очередь записи в IndexedDB (Dexie),
  повторы с растущей паузой, объединение частых правок (0,8 с), «последняя запись
  побеждает» по `updated_at`, индикатор синхронизации, плашки «Продолжить» и «Сессия
  истекла», «Обновить» и «Выйти». Формат строк таблицы — в `packages/core/src/sheets.ts`.
  По решению владельца сразу сделаны таблицы проектов и перенос заметок между ними.
  Инструкция по настройке Google — `docs/SETUP_GOOGLE.md`.

- **Этап 3.** «Поделиться» в шапке проекта (Drive `permissions.create`, роль `writer`,
  Google сам присылает письмо), «Подключить общий проект» через Google Picker с
  проверкой `meta.kind=project` и записью в лист `projects` с `role=member`, значок
  общего проекта (флаг `shared` из Drive), обновление открытого общего проекта раз в 60
  секунд, пометка недоступной таблицы с сохранением кэша. Переименование своего проекта
  меняет `meta.name` и название файла таблицы.

- **Папка на Диске** (дополнение к ТЗ после этапа 3). Таблицы создаются в папке
  «DevNotes» (`appProperties` `devnotes=folder`) в корне Диска; таблицы, созданные
  раньше в корне, один раз переносятся в неё при входе (отметка на личной таблице);
  удалённая папка создаётся заново при следующем создании таблицы; чужие проекты не
  перемещаются. В колонке `source` теперь хранится `ai_paste` или `ai_mcp`, как в
  новом ТЗ. ТЗ лежит в репозитории: `TZ.md`.

- **Этап 4.** Доска на dnd-kit: три колонки по статусам для текущей области и фильтра,
  перетаскивание мышью, касанием и с клавиатуры (стрелки переносят между колонками),
  переключатель «Сетка / Доска» в шапке (выбор запоминается в браузере). Шаблон бага
  при добавлении метки «Баг» к заметке с пустым текстом, поле «Как починил» в диалоге,
  метка «Фикс» при сохранении решения, начало решения на карточке. Выбор нескольких
  заметок флажком (на телефоне долгим нажатием), панель «Выбрано N» с «Скопировать для
  ИИ», «В архив», «Удалить». Диалог «Скопировать для ИИ»; текст собирает
  `packages/core/src/aiText.ts`, правила багов — `packages/core/src/bugs.ts`.

- **Этап 5.** «Вставить от ИИ» в шапке: три шага (скопировать инструкцию, вставить
  ответ, проверить распознанные карточки и выбрать проект), разбор по схеме zod из
  `packages/core/src/aiImport.ts` (первый блок ```json, иначе первый JSON-объект;
  обязателен только `title`; не больше 100 карточек и 10 новых меток за вставку;
  объяснение ошибок по-русски). Вид «На проверку» со счётчиком в боковой панели:
  карточки от ИИ (`source=ai_paste` или `ai_mcp`, `review=pending`) не видны в сетке,
  на доске, в поиске и счётчиках; «Принять», «Удалить», «Принять все», «Удалить все» с
  подтверждением; текст можно поправить до принятия; после принятия в диалоге пометка
  «создано ИИ».

- **Этап 6.** MCP-сервер `packages/mcp` (официальный MCP SDK 1.x, stdio). Риск с
  `drive.file` проверен на практике командой `devnotes-mcp check`: десктоп-клиент того же
  проекта Google Cloud видит и читает таблицы, созданные сайтом. Вход `devnotes-mcp login`
  (браузер, loopback 127.0.0.1, PKCE), refresh-токен в папке настроек пользователя. Пять
  команд: `list_projects`, `list_notes`, `get_note`, `create_notes` (всегда `ai_mcp` и
  «На проверку»), `update_note` (только статус, метки и решение). Разбор карточек общий с
  сайтом (`normalizeAiNotes` в `core`). Инструкция — `docs/MCP.md`.

- **Этап 7.** Телефон от 360 px: шапка с меню, иконкой поиска и «⋯» (вставить и
  скопировать для ИИ, поделиться), ряд чипов меток под быстрым вводом, «Сетка / Доска»
  внизу экрана, колонки доски листаются по горизонтали. Области нажатия не меньше 44 px
  (невидимая зона вокруг мелких кнопок). Доступность: проверка axe-core в тестах для
  основных экранов, контраст всех пар цветов из ТЗ не ниже 5:1, на доске отдельная
  кнопка переноса для клавиатуры. Манифест и иконки для установки на телефон
  (`apps/web/scripts/make-icons.mjs`). README и `docs/SETUP_GOOGLE.md` переписаны для
  человека, который разворачивает свою копию.
