# MCP-сервер DevNotes для Claude Code

MCP-сервер работает на вашем компьютере и даёт Claude Code читать и создавать карточки
DevNotes. Например: «найди баги в этом проекте и заведи карточки в DevNotes». Карточки от
Claude Code всегда попадают в «На проверку» на сайте: их нужно принять вручную.

Сервер ходит в те же Google Таблицы, что и сайт, с той же областью доступа `drive.file`,
но через отдельный OAuth-клиент типа «Desktop app» того же проекта Google Cloud. Каждый
пользователь входит своим аккаунтом и работает только со своими заметками; клиент
определяет приложение, а не пользователя.

## Пользователю сайта: одна команда

Откройте на сайте DevNotes страницу **«Подключить Claude Code»** (внизу боковой панели)
и выполните команду оттуда. Она выглядит так:

```bash
claude mcp add --transport stdio --scope user devnotes -- npx -y https://<адрес сайта>/devnotes-mcp.tgz
```

На Windows вместо `npx` пишется `cmd /c npx`. Нужны Claude Code и Node.js 22 или новее.
Клонировать репозиторий, собирать и настраивать ничего не нужно:

- пакет `devnotes-mcp.tgz` — небольшой загрузчик; при каждом запуске он скачивает с сайта
  свежую сборку сервера (если ничего не изменилось, сайт отвечает 304), а без сети
  запускает копию, сохранённую в папке настроек;
- при первой просьбе к DevNotes сервер сам откроет браузер со входом в Google: войдите
  своим аккаунтом, разрешите доступ и повторите просьбу.

Проверка — `claude mcp list` (у `devnotes` должно быть `✔ Connected`). Отключить —
`claude mcp remove devnotes --scope user`.

## Владельцу сайта: включить страницу «Подключить Claude Code»

1. Создайте OAuth-клиент «Desktop app» (шаг 1 ниже).
2. Заведите две переменные репозитория (Settings → Secrets and variables → Actions →
   **Variables**): `DEVNOTES_MCP_CLIENT_ID` и `DEVNOTES_MCP_CLIENT_SECRET`.
3. Перезапустите публикацию сайта. CI соберёт `devnotes-mcp.tgz` и
   `devnotes-mcp/server.mjs` рядом с сайтом и встроит в сборку сервера этот клиент, а
   страница покажет команду. Без переменных страница объясняет, что подключение не
   включено.

Client ID и secret Desktop-клиента окажутся в скачиваемой сборке сервера. Это нормально:
Google прямо пишет, что десктоп-приложения не могут хранить secret в тайне. Доступ к
чьим-либо данным они не дают — каждый вход подтверждает сам владелец аккаунта.

## Ручная установка (для разработки)

Шаги ниже нужны, если вы запускаете сервер из своей копии репозитория.

### 1. OAuth-клиент «Desktop app»

Делается один раз, в том же проекте Google Cloud, что и сайт (шаги 0–8 из
[SETUP_GOOGLE.md](SETUP_GOOGLE.md) уже выполнены).

1. Откройте https://console.cloud.google.com/auth/clients и проверьте, что вверху выбран
   проект `DevNotes`.
2. **Create client** → **Application type**: **Desktop app**, **Name**: `DevNotes MCP`.
3. **Create**. В окне с результатом скопируйте **Client ID** и **Client secret**.

Для десктоп-клиентов Google не считает client secret настоящим секретом: он всё равно
лежит на компьютере пользователя. Но в репозиторий и в чат его класть не нужно.

### 2. Куда положить Client ID и secret

Создайте файл `config.json` в папке настроек сервера:

| Система | Папка                                             |
| ------- | ------------------------------------------------- |
| Windows | `%APPDATA%\devnotes-mcp`                          |
| macOS   | `~/Library/Application Support/devnotes-mcp`      |
| Linux   | `~/.config/devnotes-mcp` (или `$XDG_CONFIG_HOME`) |

Содержимое:

```json
{
  "clientId": "…apps.googleusercontent.com",
  "clientSecret": "…"
}
```

Вместо файла можно задать переменные окружения `DEVNOTES_GOOGLE_CLIENT_ID` и
`DEVNOTES_GOOGLE_CLIENT_SECRET`. Другую папку настроек задаёт `DEVNOTES_MCP_HOME`.

### 3. Сборка

Нужен Node.js 22.12 или новее. В корне репозитория:

```bash
npm install
npm run build
```

Сервер собирается в `packages/mcp/dist/index.js`.

### 4. Вход

```bash
node packages/mcp/dist/index.js login
```

Откроется браузер со входом в Google. Войдите тем же аккаунтом, что и на сайте, и
разрешите доступ. После входа в папке настроек появится `token.json` с refresh-токеном,
доступным только вашему пользователю. Выйти и отозвать доступ:
`node packages/mcp/dist/index.js logout`.

Проверить, что сервер видит таблицы сайта:

```bash
node packages/mcp/dist/index.js check
```

Команда находит личную таблицу DevNotes и читает таблицы всех проектов из списка.

### 5. Подключение к Claude Code

Добавьте сервер для всех своих проектов (`--scope user`). Путь — полный путь к
`packages/mcp/dist/index.js` в вашей копии репозитория:

```bash
claude mcp add --transport stdio --scope user devnotes -- node /полный/путь/к/devnotes/packages/mcp/dist/index.js
```

На Windows путь пишется с прямыми слэшами, например
`node D:/Projects/devnotes/packages/mcp/dist/index.js`.

Только для текущего проекта — без `--scope user` (по умолчанию `local`).

Проверка:

```bash
claude mcp list
```

У `devnotes` должно быть `✔ Connected`. Внутри Claude Code то же видно по команде `/mcp`.
Если сервер не подключается, сначала проверьте вход: `node packages/mcp/dist/index.js check`.

После `git pull` пересоберите сервер (`npm run build`) и перезапустите Claude Code.

## Команды

| Команда         | Что делает                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------ |
| `list_projects` | Проекты: id, название, роль (`owner` или `member`), плюс «Без проекта» с id `none`                           |
| `list_notes`    | Заметки проекта, новые сверху, без архивных и удалённых. Фильтры `status`, `label`, `query`, `limit`         |
| `get_note`      | Одна заметка целиком, включая «Как починил»                                                                  |
| `create_notes`  | До 50 карточек в проекте. Всегда с `source=ai_mcp` и `review=pending`: они попадают в «На проверку» на сайте |
| `update_note`   | Меняет статус, метки и решение. Заголовок и текст не трогает                                                 |

Команд удаления и архивации нет, и обойти проверку нельзя: карточки от Claude Code
появляются на сайте только в «На проверку», с подписью «через Claude Code», пока вы их не
примете. Недостающие метки создаются автоматически, не больше 10 за один вызов.

Правки на сайте видны серверу сразу: он каждый раз читает таблицу заново. Карточки от
сервера появляются на сайте после очередного обновления (возврат на вкладку или кнопка
«Обновить»).

## Примеры запросов

- «Найди баги в этом проекте и заведи карточки в DevNotes, проект „Платформер“».
- «Какие баги в DevNotes в проекте „Платформер“ ещё не исправлены?»
- «Посмотри идеи в DevNotes без проекта и предложи, с какой начать».
- «Я починил баг „Меню паузы не закрывается с геймпада“: поставь ему статус „Готово“ и запиши
  решение».

## Если что-то не работает

| Что видно                                       | Что сделать                                                               |
| ----------------------------------------------- | ------------------------------------------------------------------------- |
| `Не найден OAuth-клиент «Desktop app»`          | Шаги 1–2: `config.json` в папке настроек или переменные окружения         |
| Claude Code пишет, что сервер не вошёл в Google | `node packages/mcp/dist/index.js login`                                   |
| `Личная таблица DevNotes НЕ найдена`            | Войдите на сайте этим же аккаунтом хотя бы один раз; проверьте аккаунт    |
| Вход перестал работать                          | `logout`, затем снова `login` (доступ могли отозвать в настройках Google) |
