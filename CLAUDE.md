# DevNotes — правила для Claude Code

ТЗ лежит вне репозитория: `../DevNotes — ТЗ для Claude Code.md`. Скриншоты макета:
`../DevNotes — макет сайта-png.zip`. Где мы сейчас — в [PROGRESS.md](PROGRESS.md).

- **Язык.** С владельцем по-русски, интерфейс на русском. Код, имена, комментарии и
  коммиты на английском. Строки интерфейса только в `apps/web/src/i18n`.
- **Этапы.** Строго по разделу ТЗ «Этапы разработки». После этапа остановиться,
  коротко написать, что сделано и как проверить, и ждать подтверждения.
- **Рамки.** Функций сверх ТЗ не добавлять. Свои идеи — списком в конце отчёта.
- **Документация.** Актуальные стабильные версии библиотек. По Google Identity
  Services, Sheets, Drive, Picker и MCP SDK сверяться с документацией, а не с памятью.
- **Секреты.** Ключи в чат не просить. Они в `apps/web/.env.local` (в `.gitignore`) и в
  переменных репозитория GitHub.
- **Проверки.** Этап принят, когда проходят `npm run lint`, `npm run test` и
  `npm run build`. Для `packages/core` тесты обязательны.
- **Демо-режим.** Вся работа с Google за интерфейсом `DataStore`
  (`apps/web/src/data`). Хранилище в памяти включается адресом `?demo=1` и должно
  работать всегда.
- **Макет.** Поведение из текста ТЗ, внешний вид из скриншотов и раздела «Дизайн».
  Противоречат — спросить.
- **Git.** Каждый этап в своей ветке, PR в `main`, в описании — как проверить. В `main`
  напрямую не пушить.
- **Прогресс.** В конце каждого этапа обновить `PROGRESS.md`.
