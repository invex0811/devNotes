# DevNotes

Заметки для разработчиков игр и программ в духе Google Keep: идеи, баги и фиксы со
статусами и метками, по проектам. Данные лежат в Google Таблицах самого пользователя,
своего сервера и общей базы нет — сайт статический и публикуется на GitHub Pages.

Сайт: https://invex0811.github.io/devNotes/ (демо без входа —
https://invex0811.github.io/devNotes/?demo=1).

## Что умеет

- **Заметки.** Быстрый ввод с метками по префиксу («баг: …», «идея: …», «фикс: …»),
  статусы «Новое», «В разработке», «Готово», свои метки и цвета, закрепление, архив,
  поиск, фильтры по статусу и метке.
- **Проекты.** У каждого проекта своя таблица. Проектом можно поделиться с другим
  аккаунтом Google, а он подключит его у себя через Google Picker.
- **Сетка и доска.** Доска с колонками по статусам, карточки переносятся мышью, пальцем
  и с клавиатуры.
- **Баги.** Шаблон бага, поле «Как починил», которое находится поиском.
- **ИИ.** «Скопировать для ИИ» собирает выбранные заметки в задачу для любого ИИ,
  «Вставить от ИИ» превращает его ответ в карточки. Карточки от ИИ сначала попадают в
  «На проверку».
- **Claude Code.** MCP-сервер даёт Claude Code читать заметки и заводить карточки.
  Пользователь подключает его одной командой со страницы «Подключить Claude Code» на
  сайте — см. [docs/MCP.md](docs/MCP.md).
- **Офлайн и телефон.** Заметки показываются из кэша сразу, правки без сети уходят в
  таблицу, когда сеть появится. Сайт работает от ширины 360 px и устанавливается на
  телефон как приложение.

## Демо-режим

Добавьте к адресу `?demo=1`, например `http://localhost:5173/?demo=1`. Приложение
откроется с примерами заметок и без Google. Данные хранятся только в памяти и пропадают
при обновлении страницы.

## Своя копия: с чего начать

1. Нужен Node.js 22.12 или новее.
2. Сделайте копию репозитория, установите зависимости и запустите сайт в демо-режиме:
   ```bash
   npm install
   npm run dev      # http://localhost:5173/?demo=1
   ```
3. Чтобы работал вход через Google и сайт на GitHub Pages, пройдите
   [docs/SETUP_GOOGLE.md](docs/SETUP_GOOGLE.md): проект Google Cloud, OAuth-клиент,
   API-ключ, файл `apps/web/.env.local` и переменные репозитория. Около 30 минут.
4. По желанию — MCP-сервер для Claude Code: [docs/MCP.md](docs/MCP.md).

## Команды

```bash
npm install      # установить зависимости
npm run dev      # сайт для разработки на http://localhost:5173
npm run lint     # ESLint и проверка форматирования Prettier
npm run test     # тесты Vitest (ядро, сайт, MCP-сервер)
npm run build    # проверка типов, сборка сайта (apps/web/dist) и MCP-сервера (packages/mcp/dist)
npm run format   # отформатировать код
```

## Структура

| Папка           | Что в ней                                                                |
| --------------- | ------------------------------------------------------------------------ |
| `apps/web`      | Сайт: React, TypeScript, Vite, Tailwind CSS, Zustand, Dexie, dnd-kit     |
| `packages/core` | Общее ядро: типы, zod-схемы, формат строк таблицы, текст для ИИ и разбор |
| `packages/mcp`  | MCP-сервер для Claude Code                                               |
| `docs`          | Настройка Google и MCP-сервера                                           |
| `.github`       | Проверки и публикация на GitHub Pages через GitHub Actions               |

Требования к продукту — [TZ.md](TZ.md), ход работы — [PROGRESS.md](PROGRESS.md).

## Публикация

При пуше в `main` GitHub Actions запускает проверки и публикует сайт на GitHub Pages.
Один раз в настройках репозитория нужно выбрать Settings → Pages → Source: GitHub
Actions и завести переменные `VITE_GOOGLE_*` (шаги 0 и 8 в
[docs/SETUP_GOOGLE.md](docs/SETUP_GOOGLE.md)).

## Данные и приватность

- DevNotes просит у Google только доступ `drive.file`: к файлам, которые создал сам
  DevNotes, и к тем, что пользователь выбрал в Google Picker. Остальные файлы на Диске
  ему недоступны.
- Заметки хранятся в таблицах в папке «DevNotes» на Google Диске пользователя. У
  DevNotes нет своего сервера: данные идут напрямую между браузером и Google.
- В браузере хранится кэш заметок (IndexedDB), чтобы они открывались без сети. Токен
  доступа хранится только в памяти вкладки. «Выйти» отзывает доступ и очищает кэш.
- Отозвать доступ DevNotes можно и в настройках аккаунта Google:
  https://myaccount.google.com/connections
