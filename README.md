# DevNotes

Заметки для разработчиков игр и программ в духе Google Keep: идеи, баги и фиксы
со статусами и метками, по проектам. Данные хранятся в Google Таблицах пользователя,
своего сервера нет.

Проект в разработке. Готовы этапы 0–2: каркас, заметки и вход через Google с хранением
в таблицах. Что дальше — в [PROGRESS.md](PROGRESS.md).

## Вход через Google

Сайт работает целиком в браузере: вход через Google Identity Services с одной областью
доступа `drive.file`, заметки в личной таблице «DevNotes» на Диске пользователя, у каждого
проекта своя таблица. Заметки сразу показываются из кэша в IndexedDB, правки уходят в
таблицу из очереди, которая переживает перезагрузку и отсутствие сети.

Для локальной разработки нужны ключи в `apps/web/.env.local` (образец —
`apps/web/.env.example`). Как их получить — [docs/SETUP_GOOGLE.md](docs/SETUP_GOOGLE.md).
Без ключей сайт предлагает только демо-режим.

## Демо-режим

Добавьте к адресу сайта `?demo=1`, например `http://localhost:5173/?demo=1`.
Приложение откроется с примерами заметок и без Google. Данные хранятся только
в памяти и пропадают при обновлении страницы.

## Структура

| Папка           | Что в ней                                                  |
| --------------- | ---------------------------------------------------------- |
| `apps/web`      | Сайт: React, TypeScript, Vite, Tailwind CSS                |
| `packages/core` | Общее ядро: типы, формат строк таблицы для сайта и MCP     |
| `packages/mcp`  | MCP-сервер для Claude Code (пока заглушка, будет позже)    |
| `.github`       | Проверки и публикация на GitHub Pages через GitHub Actions |

## Команды

Нужен Node.js 22.12 или новее.

```bash
npm install      # установить зависимости
npm run dev      # сайт для разработки на http://localhost:5173
npm run lint     # ESLint и проверка форматирования Prettier
npm run test     # тесты Vitest
npm run build    # проверка типов и сборка сайта в apps/web/dist
npm run format   # отформатировать код
```

## Публикация

При пуше в ветку `main` GitHub Actions запускает проверки и публикует сайт на
GitHub Pages. Один раз в настройках репозитория нужно выбрать
Settings → Pages → Source: GitHub Actions и завести переменные `VITE_GOOGLE_*`
(шаг 8 в [docs/SETUP_GOOGLE.md](docs/SETUP_GOOGLE.md)).
